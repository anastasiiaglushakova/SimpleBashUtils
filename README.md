
# SimpleBashUtils

Проект **SimpleBashUtils** реализует две базовые утилиты командной строки — `cat` и `grep` — на языке C.

---

## Реализованные утилиты

### s21_cat

- Аналог стандартной утилиты `cat`.
- Поддержка всех флагов GNU-версии `cat` (например, `-b`, `-e`, `-n`, `-s`, `-t`, и др.).
- Исходные, заголовочные и сборочные файлы расположены в директории `src/cat/`.
- Итоговый исполняемый файл — `src/cat/s21_cat`.

### s21_grep

- Аналог утилиты `grep`.
- Поддержка флагов: `-e`, `-i`, `-v`, `-c`, `-l`, `-n`.
- Использование библиотек для регулярных выражений: PCRE или POSIX regex.
- Исходные, заголовочные и Makefile находятся в директории `src/grep/`.
- Итоговый исполняемый файл — `src/grep/s21_grep`.

---

## Общие модули

Для уменьшения дублирования кода и повышения читаемости общий функционал (вспомогательные функции, структуры данных и пр.) вынесен в директорию:

```
src/common/
```

Здесь располагаются исходные и заголовочные файлы с функциями, которые используются как в `cat`, так и в `grep`.

---

## Тесты

Для проверки корректности работы утилит реализованы скрипты на bash, которые:

- Автоматически запускают утилиты `s21_cat` и `s21_grep` с набором параметров.
- Сравнивают их вывод с выводом системных команд `cat` и `grep`.
- Проверяют обработку ошибок (например, неправильные флаги, нечитаемые файлы).
- Выводят количество успешно пройденных и упавших тестов.

Для запуска тестов запустите в терминале:

```bash
cd src/cat
bash test_s21_cat.sh
```

```cd ../grep
bash test_s21_grep.sh
```

Такой подход обеспечивает удобную и быструю проверку функционала без необходимости подключения сторонних тестовых фреймворков.

## Сборка и запуск

Для сборки каждой утилиты:

```bash
cd src/cat
make
./s21_cat [опции] [файлы]

cd ../grep
make
./s21_grep [опции] [шаблон] [файлы]
```

Makefile каждой директории учитывает сборку и компоновку с общими файлами из `common`.

## Требования

- Компилятор C с поддержкой стандарта C11.
- Unix-подобная ОС.
- Библиотеки PCRE или POSIX regex (для `grep`).
- Make.
